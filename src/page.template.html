Gestos estilo Google Earth (modo predeterminado): arrastrá con un dedo para mover el mapa, separá o juntá dos dedos para acercar o alejar, girá dos dedos entre sí para rotar y deslizá ambos hacia arriba o abajo para inclinar la vista. Podés combinar zoom, giro y movimiento. El doble toque acerca; para un zoom continuo, tocá dos veces, mantené el segundo toque y deslizá verticalmente. El botón 2D/3D cambia entre vista superior e inclinada sin borrar la selección; la brújula N vuelve a orientar hacia el norte.

Modo esfera 360°: tocá 360° para rotar el modelo libremente con un dedo en cualquier dirección, también desde abajo y boca abajo; con dos dedos seguís teniendo zoom, desplazamiento y giro sobre el tercer eje. Tocá 360° otra vez para volver a la navegación tipo Google Earth. Los botones ↶ y ↷ permiten girar sobre Z. En teclado: N apunta al norte, U muestra vista superior, R o 0 restablece, Q/E gira sobre Z en modo libre y RePág/AvPág inclina. Con ratón: rueda para zoom, Mayús + rueda para inclinar, botón derecho para mover.
